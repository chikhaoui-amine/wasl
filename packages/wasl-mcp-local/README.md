# wasl-mcp-local

Direct STDIO Model Context Protocol (MCP) bridge for **WASL Local**.

This package is distributed as part of the WASL repository. It connects compatible local AI clients to an active WASL browser/PWA instance over an authenticated loopback WebSocket.

## Build

From the WASL repository root:

```bash
npm run build:mcp
```

The compiled connector entry point is:

```text
packages/wasl-mcp-local/dist/cli.js
```

## Recommended setup

1. Run WASL locally:

```bash
npm run dev
```

2. Open **Settings → AI connections**.
3. Create a connector profile for your AI client.
4. Choose its permissions and allowed domains.
5. Use the copy-ready configuration generated by WASL for that profile.

A manual STDIO command is equivalent to:

```bash
node /ABSOLUTE/PATH/TO/wasl/packages/wasl-mcp-local/dist/cli.js --secret=YOUR_CONNECTOR_SECRET
```

Use the exact command generated in WASL when possible because connector profiles may use dynamically allocated local ports and profile-specific secrets.

## Runtime boundary

- Communication stays on local loopback (`127.0.0.1`).
- The WASL browser/PWA instance must be running.
- Connector profiles can be read-only or read-write.
- Domain access is configurable per profile.
- Secrets can be rotated or revoked from WASL settings.

See [`../../docs/guides/mcp-setup.md`](../../docs/guides/mcp-setup.md) for client-specific setup examples.
